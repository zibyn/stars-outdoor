# 体验改版 v3：现状逐屏截图（模拟器）

为 [任务：模拟器逐屏截图现状](https://github.com/zibyn/stars-outdoor/issues/128) 所做，只记录事实，不评判。

## 环境

- 模拟器 AVD `dbg`：Android 15（API 35），1080×2400，420 dpi；debug 构建，main @ 3ac5be5；浅色。
- GPS 用 `adb emu geo fix` 模拟（太白山一带），只在发送时有定位，所以多处出现「正在定位」状态条，属模拟器所致。
- 服务端不可达（debug 构建指向的 API 在模拟器里连不上）：天气、队伍、登录都只截到了失败状态。
- 导入用一个自造的 GPX（60 点、1 个航点、`<trk><name>太白山南坡</name>`）。
- 每屏下方是 uiautomator 读到的文字和位置（[x1,y1][x2,y2]，像素）；`C` 表示可点击。为省篇幅，规划状态首屏常驻的 10 个按钮名从后续各屏中滤掉了。

## 截图过程中观察到的事实（未判断原因）

- 首次打开没有介绍页；进入即是规划状态首屏，顶部黄色状态条「没有定位权限，记录不到轨迹 · 点这里开启」，点后弹系统定位权限框。
- 首次开始记录时没有请求通知权限（Android 15），之后查询 POST_NOTIFICATIONS 为未授予；也没有出现电池引导。
- 记录中：数据栏可左右滑两页（第 1 页 已走 / 用时 / 爬升 / 海拔，第 2 页 配速 / 均速 / 最高海拔 / 电量）；第 2 页配速的标签为「km 用时」。
- 模拟走了约 1.1 km、约 30 s，「用时」一直显示 0:00；结束后轨迹详情的用时也是 0:00。导入的无时间轨迹用时同样显示 0:00。
- 海拔一栏一直显示 3500，而爬升累计到 96 m、最高海拔 3596。
- 一键标注后底部出现「已标注 · 撤销 · 补充」，地图上当前位置附近看不到标注的点（可能被位置点盖住）。
- 暂停后底部变为 继续 / 按住结束 / 标注；短按「按住结束」提示「按住 1 秒结束记录」。结束后自动打开刚记录的轨迹详情。
- 轨迹详情为底部抽屉；正文顺序：四项数据 → 沿轨位置 → 海拔剖面 → 正向/反向 → 设为参考/叠加到地图 → 沿线离线地图 → 坐标纠偏三选一 → 导出 → 公开到周边路网（附 50 字说明）→ 删除。轨迹名默认是日期时间。
- 导入 GPX 后直接打开轨迹详情，没有「已导入」提示；轨迹名用了文件名 `taibai`，而不是 GPX 里的 `太白山南坡`。
- 「我的轨迹」列表每行只有日期时间和「叠加」按钮，没有距离等数据；长按与点按一样打开详情。
- 在「我的轨迹」页点空白处（右下，地图「标注」按钮的位置），触发了下层地图的一键标注，页面上弹出「已标注」。
- 队伍页为整页，含一段 45 字说明；不登录点「建队」或输入加入码点「加入」后，6 s 内无任何提示、加载状态或登录页。
- 账号页不可达服务端时提示「短信暂时发不出去，过几分钟再获取验证码」。
- 天气无网络时只有一行「暂无天气，联网后再打开」。
- 飞行模式下状态条「离线中：已下载的地图和记录照常可用」；搜索「没有找到（没有网络）」（已导入离线底图但无地名索引）；切卫星后状态条「卫星图离线用不了 · 切到地形」，并显示「+1」表示还有一条状态被折叠。
- 定位关闭时仍可开始记录；结束后保存了一条 0 m 的轨迹并提示「已保存 · 0 m」。
- 清除应用数据后，离线地图页仍列出 3 个 pmtiles 文件（共 20 MB）。
- 设置页：惯用手、地图缓存（含 40 字说明）、防止后台停掉记录（弹窗，约 80 字）、账号与同步、关于。关于页 6 段数据来源文字，版本显示为「（1）」。
- 规划状态首屏：右上 搜索 / 天气 / 图层 三个圆形图标钮；右下 定位 / 标注；底栏 我的轨迹 / 队伍 / 开始（居中大绿钮）/ 离线地图 / 设置。活动状态：顶部深色数据栏，左侧 队伍 / 分享位置 / 更多，右侧 图层 / 放大 / 缩小 / 定位，底部 暂停 / 标注 两个大键。
