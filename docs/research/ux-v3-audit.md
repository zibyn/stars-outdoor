## 3. 按路径的设计问题（并进各路径的逐步方案）

**① 首次打开**
- 1a 中：第一屏的第一句就是黄色报错状态条，没有介绍
- 1b 中：不给定位权限时，地图停在太白山
- 1c 中：从不提下载离线地图
- 1d 中：电池引导只在设参考或沿线下载后才出现

**③ 记录**
- 3a 中：暂停后没有「已暂停」（方案里显示「已暂停 · 时长」）
- 3b 中：结束后没有起名的时机
- 3c 中：「分享位置」和「共享位置」只差一个字（方案里不在队伍时，「分享位置」直接打开系统分享）
- 3d 低：「更多」抽屉遮挡、没有动画；页码点 8 dp

**② 出发前规划**
- 2a 中：轨迹详情太长，四个同样的绿色主按钮；导出、删除要 4–5 次点击加滚动
- 2b 中：坐标纠偏常驻，录制的轨迹也显示
- 2c 中：「日期」格和默认名重复
- 2d 中：沿线下载不确认、不说大小，和「下载这附近」不一致
- 2e 中：周边路网开了看不出，点空处无反馈
- 2f 中：沿途天气离线时大半屏空白，空胶囊仍可点
- 2g 低：搜索没有加载状态；拼音结果压过距离；结果行没有距离和类别
- 2h 低：设为参考后详情不关，挡住参考条

**⑤ 管理**
- 5a **高**：列表没有距离、爬升、日期
- 5b 中：从列表打开详情，返回回到地图
- 5c 中：删除后没有提示、不能撤销（方案里加撤销）
- 5d 中：在列表里叠加看不到效果
- 5e 中：标注页没有空状态；新建标注组没有占位、没有取消，空名静默
- 5f 中：离线包看不出覆盖范围

**④ 队伍**
- 4a 中：被邀请的人要点的「加入」是灰色次按钮
- 4b 中：新队伍对话页空白，邀请藏两层（方案里空状态显示加入码和「邀请」）
- 4c 中：刚建队显示「队伍 0」
- 4d 中：结束行程后没有「新建或加入队伍」
- 4e 中：绑定队伍轨迹的列表没有距离（同 5a）
- 实时连接断开的指示：由 [#137](https://github.com/zibyn/stars-outdoor/issues/137) 承担

**⑥ 设置、账号**
- 6a 中：设置各行看不出能不能点；未选中的灰字像禁用
- 6b 中：退出登录没有确认，还会顺带退出队伍
- 6c 中：偏离提醒阈值（v2 列了，未实现）
- 6d 低：清除缓存没有确认

**⑦ 横向检查表的缺口**（完整表见附录 C）
- 没有加载状态：搜索、周边路网、队伍信息
- 没有空状态：标注页、对话页
- 静默失败：设置里清除缓存失败时不提示

## 4. 文字过多

| 位置 | 说明字数 |
|---|---|
| 关于 · 数据来源 5 段 | ≈250 |
| 电池引导弹窗 | 77 |
| 注销确认 | 58 |
| 账号页顶部 | 50 |
| 轨迹详情 · 公开说明 | ≈47 |
| 队伍页顶部 | 45 |
| 设置 · 地图缓存说明 | 43 |
| 账号 · 同步说明 | 41 |
| 离线地图空状态 | 31 |

字数只算说明性文字，按钮名、标签、数字不算。处理顺序：**能删就删 → 换成图标、数字或输入框前缀（如 +86）→ 到要用时才出现（如「公开」的后果放进「再点一次」的确认）→ 默认收起成 ⓘ**。分步操作（电池引导）改成编号步骤，每步配一个按钮。每屏上限在原型时定。

关于页的数据来源是许可要求（OSM ODbL、天地图、和风天气），不能删：改成「数据来源 ›」二级页，用 来源 / 许可 两列表格；地图角标署名保留。

## 5. 新功能候选

**开评估 ticket**：
- F1 首次打开：一句话介绍 + 引导下载离线地图
- F2 出发前检查：定位、通知、电池优化（能回读电池优化是否已关）
- F3 结束时自动起名
- F4 我的轨迹排序、筛选
- F5 离线包：下载前估算大小、在地图上显示范围
- F6 队伍邀请链接或二维码

**并进路径方案、不算新功能**：已暂停时长、删除撤销、对话空状态带加入码、偏离提醒阈值、「分享位置」直接打开系统分享。

**未采纳**：批量管理、地点页「附近路线」、队友小抽屉里的「发位置 / 指向」、未登录保存后提醒登录备份。

**超出范围**：在 App 里画计划路线（独立大模块）、按出发时间看沿途天气（ADR 0011）、检查更新（#51）。
