## 1. 范围与约束

**做**：设计令牌、动效、无障碍指标、骨架、反馈载体、横向检查表、7 条核心路径（① 首次打开 ② 出发前规划 ③ 记录 ④ 队伍 ⑤ 管理 ⑥ 设置、账号、离线地图 ⑦ 横向状态）逐步方案、获批的新功能（§9）、全量文案。数据、接口、服务端都可以改（§10）。

**不做**：用户自定义界面（自选数据项、主题色、底栏配置）；App 启动图标（#80）；精选线路、社交内容、在 App 里画计划路线等独立大模块；按出发时间看沿途天气（ADR 0011）；检查更新（#51）；繁体和英文文案。

**原则**
- **弱化大段文字**：户外不读长句。能用图标、数字、图形、颜色表达的不用句子；处理顺序 删 → 换图标 / 数字 / 前缀 → 用到时才出现 → 收进 ⓘ。每屏文字上限见 §7.2。
- **表现力收着用**：M3 Expressive 为底，弹簧和变形只用在开始、结束记录两个时刻（§3）。
- **浮层实底**：地图上的浮层 100% 不透明，不做半透明和模糊。
- **深色跟随系统**，底图也有深色（§2.8）；不用动态取色。

**审查里的 bug** 不等 v3，已单独开（#133–#150）。切片若顺带修掉，在 issue 里写 `Closes #n`（§12 列了对应）。

## 2. 设计令牌

来源：[决定：设计令牌定稿](https://github.com/zibyn/stars-outdoor/issues/158)、[原型：整体视觉风格方向](https://github.com/zibyn/stars-outdoor/issues/130)、[调研：在现有 Compose 工程引入 Material 3 Expressive 的代价](https://github.com/zibyn/stars-outdoor/issues/127)。

### 2.1 依赖与主题

- 引入 `androidx.compose.material3:material3:1.5.0-alpha27`（**钉死这个版本**：它依赖 foundation 1.12.0-beta01，在本工程解析成现有的 1.12.0；alpha28 起要求 foundation 1.13.0-alpha01）。仍需 `@ExperimentalMaterial3ExpressiveApi` 的只有 `LoadingIndicator`、`MaterialShapes`、一个 `DropdownMenuItem` 重载和 `TonalToggleButton`，本规格都不用（形状变形除外，见 §3）。
- APK：不开 R8 +2.4 MB，开 R8 +0.6 MB。开 R8 另见 #132。
- 用 `MaterialExpressiveTheme`（或 `MaterialTheme`）包住整个 App，浅 / 深两套 `ColorScheme` 按 `isSystemInDarkTheme()` 切换。**所有颜色从主题取**，删掉现在写死的颜色字面量（审查 S1：25 种字面量、5 种红、3 种近黑）。

### 2.2 对比度目标（户外）

- 主文字和大字数据 ≥ 7:1；次要文字和标签 ≥ 4.5:1；图标和控件边界 ≥ 3:1。
- 地图上的线、我的位置、队友点**一律加描边**（浅色界面白边，深色界面近黑边），线色和描边之间 ≥ 3:1。

- **队友一律用紫**，取消每人一色的 `memberColor`（8 种）。圆点上显示头像，没有头像写昵称首字（§8.4）；在成员列表里点某人，地图上高亮他的尾迹。
- **叠加 4 色，按顺序循环，不设条数上限**（第 5 条回到玫红）。叠加线比记录线和参考线细一档（约 3 dp 对 5 dp）。

### 2.5 字号阶梯

现在 16 种 → 6 级；**数字一律用等宽数字**（`fontFeatureSettings = "tnum"`）；字体用系统字体。

| 级 | 字号 / 字重 | 用在 |
|---|---|---|
| 大数 | 36 sp / 粗 | 轨迹详情的主数字 |
| 数据 | 24 sp / 粗 | 数据窄条、详情里的数据格 |
| 标题 | 20 sp / 粗 | 页面标题、抽屉标题 |
| 正文 | 16 sp | 列表主行、按钮、提示条 |
| 次要 | 14 sp | 列表副行 |
| 标签 | 12 sp / 中 | 单位、数据格下的标签、底栏文字 |

最小 12 sp，取消 9–11 sp。提示条只用一档大字（#151）。放大规则见 §4.3。

### 2.6 形状

- 小 12：输入框、小卡片、数据格、标注组色块。
- 中 16：地图浮动按钮（图层、定位）、卡片。
- 大 24：抽屉和底部面板的上沿、对话框。
- 全圆：所有按钮、底栏、数据窄条、提示条、筛选胶囊、头像和队友点。

### 2.7 间距和高程

- 4 dp 网格，只用 4 / 8 / 12 / 16 / 24 / 32；整页左右边距 16，地图浮层离屏幕边 12。
- 地图浮层：实底 + 约 2 dp 投影；抽屉和面板：约 6 dp 投影。深色下浮层改加 1 dp outline 色边。取代 v2 §7「白色按钮加 1.5 dp 深色半透明描边」。

### 2.8 深色底图

`basemapStyle` 的 `remember` key 加上 `isSystemInDarkTheme()`。

- 地形：自做一份深色配色（style.json 里 57 种颜色）。
- OFM：换成 `dark` 样式。
- 天地图栅格：`raster-brightness-max` 压暗到约 0.7，**可调参数，到真机上定**，不反色。
- 卫星：不改；界面照样跟系统深浅色，线靠描边看清。

### 2.9 图标

沿用 v2 §7（Material Symbols Outlined，复制 XML，24 dp，平时线性、选中和跟随填充）。变化：
- 去掉「分享位置」「更多」两个键的图标；标注键改成带字的「⊕ 标注」（§5.4）。
- 新增：类别图标（山峰 / 村镇 / 水体 / 景点）、离线包类型图标（沿线 / 附近 / 导入）、计划轨迹图标、已公开 / 参考中小图标、标注组 📁、位置 📍、图片 🖼、发送、ⓘ、⋮、邀请。具体 symbol 名在切片里定。
- 加载指示器一律 `CircularProgressIndicator`（§3）。

## 3. 动效

来源：[决定：动效规范](https://github.com/zibyn/stars-outdoor/issues/167)。取代 v2 §5 的三档时长，相机部分沿用。

1. **令牌**：全局 `MaterialTheme.motionScheme = MotionScheme.standard()`（弹簧、基本不回弹），组件和自写动效都从它取。删除 v2 快 / 标准两档常量。
2. **地图相机**保留时长：回位 300 ms、聚焦 400 ms、跟随 1 秒线性、超过约 3 屏直接跳。
3. **表现力时刻只有两个**：开始记录（▶ 变形成 ⏸、数据窄条带弹性升起）和结束记录（按住完成后窄条收回、⏸ 变回 ▶），局部用 `MotionScheme.expressive()` + 形状变化。标注落点用 standard。没有「到达」时刻。
4. **各元素**

| 元素 | 怎么动 |
|---|---|
| 数据窄条 | 从底栏后面上滑，位移弹簧 |
| 暂停小栏 | 从 ⏸ 原点缩放 + 淡入 |
| 地图抽屉 | 上滑、高度随弹簧；抽屉内换内容（列表 → 详情）只淡入淡出，抽屉不重弹 |
| 提示条 | 淡入 + 上移 8 dp；消失只淡出；换条先出后进 |
| 状态条 | 高度展开 / 收起；换事项时文字交叉淡入淡出 |
| 整页 | 前进从右轻推、旧页淡出；返回相反 |

5. **系统「移除动画」**：所有过渡瞬间完成，表现力时刻也一样（▶ / ⏸ 直接换图标）；相机直接跳；按住结束的 1 秒进度照常。
6. **不做动效**：数字变化、列表项入场、测距横幅、记录中的红点（不闪）、软删除的行消失和恢复、头像。
7. **加载**：`CircularProgressIndicator`，300 ms 内不显示；一键标注的转圈也换成它。

## 4. 无障碍与户外可读性

来源：[决定：无障碍与户外可读性硬指标](https://github.com/zibyn/stars-outdoor/issues/168)。

### 4.1 点击区
- 通用 **48 dp**：整页、抽屉、列表行、⋮。图标可以看起来小（24 dp 图标配 40 dp 底），能点的范围补到 48。
- 地图主界面 **56 dp**：底栏、圆键列、数据窄条上的按钮、提示条和状态条上的操作。
- 相邻点击区之间 ≥ 8 dp。不设例外（「+N」、天气胶囊、坐标来源选项、测距「结束」都补齐）。

### 4.2 戴手套
- 记录中的操作一律 56 dp；记录中不用双击、不用滑动确认；保留「按住结束」。
- 「继续 / 按住结束」两个按钮之间 ≥ 16 dp。
- 不做音量键操作，不做语音。

### 4.3 字体放大
- 整页和抽屉跟随系统到 200%，放不下就换行，不截断。
- 地图浮层（数据窄条、状态条、提示条、底栏文字）最多放大 1.3 倍。

### 4.4 强光
- 不按光线切深浅色、不常亮、不调亮度；靠 7:1 对比度、描边和粗数字。
- **颜色不单独表意**：偏离时警示色 + ⚠ + 「偏离 50 m」；队友靠头像或首字区分。

### 4.5 TalkBack
1. 只有图标的按钮都有标签，≤ 4 字，和屏幕上同一概念用同一个词（R26）；装饰图标不读。
2. 窄条和数据格按一组读：「已走 3.2 公里，用时 1 小时 5 分」。
3. 状态条、提示条用礼貌播报（polite live region）。
4. 地图本身不读屏；信息另有入口（队友去成员列表，轨迹去我的轨迹）。
5. 自定义手势（按住结束）保留读屏能触发的替代操作。

### 4.6 验收（每张切片都写）
- Accessibility Scanner 扫切片涉及的屏：点击区、对比度 0 条警告。
- 开 TalkBack 把这条路径走一遍。
- 1.3 倍和 2.0 倍字号各截一张图。
- 浅色、深色各截一张图。

## 5. 骨架

来源：[决定：整体骨架的去留](https://github.com/zibyn/stars-outdoor/issues/131)、[ADR 0012](../adr/0012-one-main-screen-recording-adds-a-data-strip.md)；顶栏规则按 [方案：⑥](https://github.com/zibyn/stars-outdoor/issues/165) 改过。

### 5.1 一套主界面

取消 v2 的规划 / 活动两种状态。记录与否布局不变，记录时只多一条数据窄条。术语「规划状态」「活动状态」落地后作废，改说「记录中」。

```
┌────────────────────────────┐
│ [搜索…………]  [天气] [图层] │  ← 顶部：搜索、天气、图层
│ ⚠ 状态条（有事才出）        │
│                            │
│            地图         [⊕]│  ← 惯用手一侧圆键列：
│                         [◎]│     标注、定位、指南针
│                            │
│ ┄┄ 提示条预留一条高度 ┄┄   │
│ [ 已走 · 用时 · 爬升 ]     │  ← 数据窄条（记录中 / 有参考时）
├────────────────────────────┤
│ 轨迹  队伍  [▶]  离线  设置 │  ← 底栏，始终显示
└────────────────────────────┘
```

### 5.2 底栏
- 五项：我的轨迹 / 队伍 / ▶ 开始 / 离线地图 / 设置；M3 贴底栏，不改成浮动工具栏或 Tab。
- 「队伍」不带人数，有未读时带红点。
- 记录中 ▶ 变 ⏸；点 ⏸ 在底栏上方弹出小栏「继续 / 按住结束」（按住 1 秒），常驻到回答，底栏不变。

### 5.3 数据窄条
- 底栏上方一行三格大字，全圆形状。
- 出现时机：记录中，或设了参考轨迹（不记录也有）。内容见 §8.3。
- 上拉 = 三列数据面板（取代 v2 的翻页和页码点）；轨迹详情用同一种「窄条 + 上拉」形式。
- 参考轨迹条并进窄条，不再单独一条（取代 v2 §3.2）。

### 5.4 圆键列与惯用手
- 惯用手一侧一列：⊕ 标注（带字的大键，≥ 56 dp）、定位、指南针。定位按钮三态、指南针沿用 v2 §3.5。
- 数据窄条和圆键列之间**固定留一条提示条的高度**；没有提示条时露出地图。暂停小栏占这一条时，提示条和圆键再往上挪一条。标注键位置因此固定。
- 惯用手镜像只换圆键列和暂停小栏；底栏、顶部、窄条不动。
- 去掉 v2 活动状态的队伍、分享位置、更多三个键。分享位置拆开：在队伍里用对话的「📍 位置」；不在队伍里点地图上我的位置，出小抽屉「分享坐标 / 标注这里」。

### 5.5 抽屉与整页
- **我的轨迹是地图上的抽屉**，半屏 / 全屏两档；列表、轨迹详情、组内列表、标注编辑都在同一个抽屉里接上，返回回到上一层，保持滚动位置、页签和抽屉高度，镜头不移回去。结束记录或导入后自动打开的详情，返回直接关抽屉。
- 抽屉盖住底栏；记录中抽屉顶部保留一行只读数据，点一下收起抽屉。
- 小抽屉：地点、队友、⋮ 二级（公开、导出、新建组、昵称、注销、出发前检查等）。
- **整页**：搜索、天气、离线地图管理、设置、队伍、队伍信息、登录、账号、关于、数据来源。M3 小号顶栏，标题一种字号，最多两个动作，系统返回键和顶栏 ← 行为一致。
- **← 规则**：底栏直达的一级页（设置、离线地图、队伍）不放 ←，系统返回回地图；从它们进去的二级页才放 ←。
- 图层抽屉里我的轨迹一组改成「已叠加 n 条 · 全部取消」，n = 0 时不显示。

### 5.6 地图视觉层级

沿用 v2 §3.8 的层序（记录线 > 参考轨迹 > 叠加 > 尾迹 > 周边路网；点在线之上），颜色和线宽改为 §2.3、§2.4：记录线橙、参考轨迹青、我的位置蓝、队友紫，线和点都加描边，叠加细一档。周边路网打开时线加粗、加描边（§8.2）。

### 5.7 距离阈值

沿用 v2 §3.7。偏离提醒阈值改为设置里可选 30 / 50 / 100 m（默认 50，§8.6）。

## 6. 反馈载体

来源：[决定：反馈载体规则](https://github.com/zibyn/stars-outdoor/issues/151)，按 #162、#169 补过。

**一直存在的用状态条，发生了一次的用提示条，填错了的写在页内。**

| 信息 | 例子 | 载体 |
|---|---|---|
| 持续状态 | 没有网络、定位已关闭、离线地图下载中 | 状态条 |
| 一次性结果 | 已保存、已导入、已登录 | 提示条 4 秒 |
| 可撤销 / 可重试 | 已标注（撤销 / 补充）、没发出（重试） | 提示条带操作 8 秒 |
| 需要回答 | 首次介绍、出发前检查提醒、记录中断了 | 常驻提示条，回答才消失 |
| 输入出错 | 组名重复、验证码不对 | 页内，紧挨出错处 |
| App 在后台 | 偏离提醒、队伍消息 | 系统通知 |

- **取消 Toast**（现有 23 处，都在 `MainActivity.kt`），按上表重新归类。
- **状态条**：地图顶部；整页只在队伍、队伍信息、对话、账号、登录、搜索、天气的顶栏下显示离线类。同时多件只显示一条，优先级：记录中的定位问题 > 没有网络 > 不记录时的定位问题 > 下载中 > 同步失败；不再有「+2」展开。下载进度在状态条（取代关不掉的提示条）。没定位只有两种说法（R8）；没权限不出状态条。
- **提示条位置**：贴着底部占位的东西往上放，永远不盖控件——地图上在底栏上方（记录中在窄条上方的预留条里）；抽屉打开时贴抽屉顶边；整页在输入行或底部按钮上方。取代「固定离底 96 dp」。
- **同一时间只显示一条提示条**；新来的一次性提示条暂时盖住常驻的，消失后常驻的回来。
- **写法**：整句 ≤ 14 字 + 最多两个操作；结果和原因用「 · 」接；出错前置 ⚠，其他不带 ✓ / ⏳（R9）。
- **震动**：开始、暂停、继续、结束（按住计时完成）、标注成功各一下；偏离提醒长震；状态条、提示条、出错、普通按钮都不震。

## 7. 横向检查表

### 7.1 状态 × 标准做法

| 状态 | 载体 | 做法 | 文字上限 | 动作 |
|---|---|---|---|---|
| 首次 | 常驻提示条，同一时刻最多一张 | 以「做过」判断，不以「看过」；不做遮罩和气泡 | 14 字 | 做过那件事后自动消失，或「知道了」 |
| 缺权限 | 用到时直接弹系统框，不加解释页 | 功能不因此消失 | 用到的位置一句 | 永久拒绝时先出提示条［去开启］，点了跳应用设置 |
| 空 | 页内 | 大图标 + 一句 + 一个主按钮（三样都要） | 16 字 | 主按钮说下一步 |

| 出错 | 填错页内；操作失败提示条 | 「⚠ {结果} · {原因}」；原因四类：没有网络 / 服务器出错 / {内容}不对·读不了 / 手机空间不足；少见本机错误「{动作}没成功」；不许静默失败 | 14 字 | 能重试就必须有［重试］；空间不足配［去清理］ |

| 没有定位 | 状态条两种：「定位已关闭」［去打开］/「信号弱 · 到开阔处」 | 依赖位置的数字显示「—」（不显示 0 或旧值）；用时照走 | 12 字 | — |

### 7.2 每屏文字上限

只算说明性文字（按钮名、标签、数字不算）。

- 地图主界面 / 记录中：说明 0 句，只有状态条和提示条各一句。
- 抽屉 / 整页：最多 1 句、≤ 20 字；更多收进 ⓘ。
- 单句上限：状态条 12、提示条 14、空状态 16、记录中主句 8、按钮 4（例外「再点一次{动作}」「获取验证码」）。
- 许可署名（数据来源页）不受限。

## 8. 路径逐步方案

### 8.1 ① 首次打开

来源：[方案：① 首次打开的逐步方案](https://github.com/zibyn/stars-outdoor/issues/160)、[评估：首次打开的一句话介绍和离线地图引导](https://github.com/zibyn/stars-outdoor/issues/152)。原型 `prototype/ux-v3-first-open`。文案 ①（C1-xx）。

1. **启动**：Android 12 起的系统启动画面（`core-splashscreen`，图标 + 底色，跟随深浅色），不做自定义闪屏。
2. **首屏**：没给定位时显示中国全图（zoom ≈ 3.5），取代写死的太白山。屏上只有介绍提示条（常驻）：一句介绍 +［稍后］［开定位］。显示期间不出定位状态条。只出一次，两个按钮都算答过。
3. **［开定位］**：直接弹系统框。
   - 精确：等第一次定位时状态条「信号弱 · 到开阔处」；定到后相机飞到我的位置，不加提示条、不震。
   - 只给大致：画大致位置的圈，不报错；开始记录时由出发前检查要精确位置（§8.3）。
   - 给了权限但定位开关关着：同一次点击里接着跳系统定位设置（没有 GMS），回来自动重读。
4. **［稍后］或拒绝**：提示条消失，**不出状态条**，停在中国全图。用到定位时（定位按钮、开始、进队伍）再弹系统框；永久拒绝后出提示条［去开启］（8 秒）→ 应用设置页。
5. 首次不问通知、不提登录。
6. **第一次打开就没网**：不内置底图，地图空白，状态条「没有网络」，介绍提示条照常。
7. **不做**：欢迎页 / 轮播；首次引导下载离线地图（改在轨迹详情提醒，§8.2）；未登录保存后提醒备份；内置低缩放底图（有人反馈白屏再加）。

### 8.2 ② 出发前规划

来源：[方案：② 出发前规划的逐步方案](https://github.com/zibyn/stars-outdoor/issues/161)、[评估：离线包下载前估算大小、在地图上显示范围](https://github.com/zibyn/stars-outdoor/issues/156)、#152、#153。原型 `prototype/ux-v3-planning`。文案 ②（C2-xx）。

**搜索**
1. 结果行：类别图标（山峰 / 村镇 / 水体 / 景点）+ 名称 + 区县 + 方向箭头和距离（有定位按离我，没有按地图中心）。排序：汉字全匹配 → 汉字前缀 → 拼音，同档按距离。先出本机离线地名；300 ms 后输入框右侧转圈。
2. 空输入只显示占位，不做最近搜索。
3. 选中 → 回地图，镜头飞过去，打开**地点小抽屉**：标题用地名，小字区县和坐标。动作［天气］［下载附近］［标注］（默认名用地名）；测距、复制坐标、分享坐标收进 ⋮（R25）。长按地图打开同一个小抽屉，标题用最近地名，查不到用坐标。

**导入**
4. 入口：我的轨迹抽屉轨迹页签顶栏「＋」（导入中换转圈）。一条：提示条「已导入 · 172 km」并接上详情（返回关抽屉）；多条：提示条「已导入 3 条」，停在列表，新的在最上面。「用其他应用打开」同流程。失败按四类原因。轨迹名仍用文件名（#123）。

**轨迹详情**（在我的轨迹抽屉里）
5. 四个数：已走距离 / 爬升 / 下降 / 用时；计划轨迹和没有时间的轨迹，「用时」换「最高海拔」。去掉日期格。第二行「距我」或「沿轨 · 剩余」，没定位写「—」。
6. 主操作排（ButtonGroup，只有一个实心）：［设为参考］/［叠加］/［下载沿线］。状态：设好后写［取消参考］、［取消叠加］；下载中「42%」；下好「已下载」；超出单包上限「范围太大」（不能点，按外接范围判断）。**按钮上不写大小**。录过的轨迹也用这一排。
7. ［设为参考］：抽屉收起，镜头看全线，提示条［撤销］8 秒；之后底栏上方出参考窄条（§8.3）。
8. ⋮：改名 / 坐标来源（只有导入的轨迹有，原「纠偏」）/ 导出 / 公开 / 删除。删除 = 软删除 + 撤销。［公开］先出小抽屉：两行图标要点（他人在周边路网可见 · 起终点各隐藏 200 m）+［公开］；公开后名字旁「已公开」标签，⋮ 里变「撤回公开」。未登录点公开 → 登录页。删掉 47 字说明。
9. 参考轨迹上有一行「出发前检查」，只列没过的项的图标，全过不显示（§8.3）。
10. **离线引导**：打开一条没下沿线离线包的轨迹详情时，出提示条「沿线还没下离线地图」［下载］；只在头 3 次出现，下过任意离线包后不再出现，可关。

**离线下载**
11. ［下载沿线］［下载附近］点一次就开始，不确认、不估大小。进度在按钮（「42%」）和状态条（「离线地图下载中 45%」）。下好：详情还开着就只在按钮原位变；已关就出提示条「离线地图已下载」［查看］。包名：沿线包和轨迹同名，附近包「{地名}附近」，类型靠图标。
12. 「范围太大」按外接范围在手机上判断，不等服务端报错。

**天气**
13. 「我的位置」没定位：数字「—」+ 空状态「定位后显示天气」。没网没缓存：空状态 + 重试。有缓存：标「3 小时前」，过期部分变淡。沿途天气没数据：剖面照常（加纵轴海拔），起终点胶囊不显示。删副标题；数据来源移到关于页。风力一律用「级」。

**周边路网**
14. 打开后线加粗、加描边；点空处提示条「这里没有路网轨迹」；查询超 300 ms 在点击处转圈。从路网保存的轨迹名去掉保存日期。界面上简称「路网」，不出现 OSM。

**不做**：搜索最近记录；「这片有 n 条」；下载前估算大小。

屏 × 状态矩阵：见 [#161 结论](https://github.com/zibyn/stars-outdoor/issues/161)。

### 8.3 ③ 记录

来源：[方案：③ 记录的逐步方案](https://github.com/zibyn/stars-outdoor/issues/162)、[评估：出发前检查](https://github.com/zibyn/stars-outdoor/issues/153)、[评估：结束记录时自动起名](https://github.com/zibyn/stars-outdoor/issues/154)。原型 `prototype/ux-v3-recording`。文案 ③、⑦（C3-xx、C7-xx）。

**出发前检查**（新功能，取代电池引导弹窗、`PREF_BATTERY_SET` 和轨迹详情的电池引导行）
1. 五项，都按手机实际状态回读：定位权限（要**精确**位置）、定位开关、通知权限、系统电池优化（`isIgnoringBatteryOptimizations`）、离线地图（当前位置或参考轨迹不在任何离线包里且有网）。厂商自启动读不到，不成项。
2. **拦**：定位两项不过录不了。按 ▶ 直接走系统授权 / 精确位置 / 定位设置，办好自动开始（同现在的 `resumeAfterGrant`）；拒绝则留在原地，提示条［去开启］。
3. **只提醒**：其余三项按 ▶ 立刻开始，然后在预留条里出常驻提示条，一次一项、带「1/3」，顺序 电池 → 离线 → 通知。电池［去关闭］直接调 `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`，回来重读；通知先请求，系统不再弹时跳应用通知设置；离线直接开始沿线 / 附近下载。
4. 跳过即收起，本次不再提，不转状态条。每次开始都重新判断；同一项连跳 3 次后开始时不再提（详情和设置照常显示）。离线一项只在有网时提。
5. **抽屉**：轨迹详情（参考轨迹那一行）和设置页「出发前检查」打开同一个小抽屉，五项各一行：过了 ✓，没过［去开启］/［去关闭］/［下载］。小米、华为等品牌在电池一行下加一行小字和［去开启］（应用设置），开始时不提。

**开始**
6. 反馈：震动 + ▶ 变形成 ⏸ + 窄条弹性升起（表现力时刻）；不出「开始记录」提示条。在队伍里先出一次「队友能看到你」，排在出发前检查提醒前面。

**记录中**
7. 窄条三格：没参考 = 已走 · 用时 · 爬升；有参考 = 剩余 · 剩余爬升 · 用时。记录中不放 ✕。
8. 不记录但有参考：窄条「沿轨 · 剩余 · 剩余爬升 · ✕」（✕ 取消参考 + 撤销）。开始记录后同一条窄条换成上面的三格，不换位置。
9. 上拉三列面板：已走、用时、爬升、下降、海拔、最高海拔、km 用时、均速、电量；有参考加沿轨、剩余、剩余爬升和［取消参考］。
10. 写法：进行中用时一律 时:分:秒（0:00:52），配速 8′30″ /km（R5）。
11. **偏离**：整条窄条换警示色 + ⚠，「剩余」格换「偏离 150 m」，长震 + 通知；回到轨迹恢复，不再提示。**信号弱**：数字变淡，偏离提醒暂停。**没定位**：数字「—」，用时照走。

**标注**
12. 「⊕ 标注」大键。按下：震动 + 大头针画在我的位置**上面**并落下 + 提示条［撤销］［补充］8 秒；［补充］开小抽屉（名称、照片）。精度不够时大键转圈，60 秒后问（沿用 v2 §9.1 门槛）。默认名「{最近地名}附近」，查不到「10月3日 14:32」（R13）。

**暂停 / 继续**
13. ⏸ → 小栏「继续 / 按住结束」常驻。窄条变淡，「用时」格换「已暂停 0:05:32」（这个数在走），用时本身停住、上拉可见。暂停期间不出定位状态条。继续也震。不做「暂停太久」提醒。

**结束**
14. 按住 1 秒（进度填满 + 震动）→ 自动起名 → 窄条收回、⏸ 变回 ▶（表现力时刻）→ 我的轨迹抽屉半屏打开详情 + 提示条「已保存 · 11.2 km」，返回直接关抽屉。不做完成页。
15. **自动起名**（新功能）：「区县 + 日期」，如「崇礼区 10月5日」。区县取起点最近一条地名（地名索引带省 / 市 / 县），没有区县用市；找不到地区（没离线包、海外）只写「10月5日」。不联网、不弹窗、不加改名按钮，起好后不再自动改；同天同区县重名接受。
16. 按得太短：提示条「按住结束」。一个点都没有：不保存，提示条说明。很短的轨迹照存。
17. 参考轨迹结束后保留，窄条回到不记录时的样子。

**中断恢复**
18. 弹窗改常驻提示条「⚠ 记录中断了」［继续］［结束］，地图上照常画已记下的线。点［继续］后若电池优化没关，这次一定再提电池一项（不受连跳 3 次限制）。［结束］直接保存。

**通知栏**
19. 记录中：主行「记录中 · 3.21 km · 0:58:12」（有参考写剩余），按钮 标注 / 暂停；暂停：「已暂停 · 0:05:32」，按钮 继续。不放结束。同时共享位置时合成一条，副行「队伍 4827 共享中」，加第三个按钮 停止共享（R23）。

**提醒**
20. 天气风险（前台）：提示条「⚠ 3 小时内有雷雨」［看天气］8 秒，通知照发，窄条不加标记。
21. 电量降到 20% 出一次提示条（4 秒），面板电量格变警示色；不用状态条，15% 以下不再提。

**回看**：照 §8.2 轨迹详情；录过的轨迹 ⋮ 没有坐标来源。

**不做**：「开始记录」提示条、完成页 / 成绩卡、暂停太久提醒、记录中窄条 ✕、通知里的结束、电量状态条。

屏 × 状态矩阵：见 [#162 结论](https://github.com/zibyn/stars-outdoor/issues/162)。

### 8.4 ④ 队伍

来源：[方案：④ 队伍的逐步方案](https://github.com/zibyn/stars-outdoor/issues/163)、[评估：队伍邀请链接或二维码](https://github.com/zibyn/stars-outdoor/issues/157)、[评估：个人信息（自动昵称、自定义头像）](https://github.com/zibyn/stars-outdoor/issues/166)。原型 `prototype/ux-v3-team`。文案 ④（C4-xx）、服务端（CS-xx）。

**进队伍**
1. **队伍页**（一级页，无 ←）：去掉 45 字说明，换图标 + 一句。输码在上：四格大字，打开就弹数字键盘；**剪贴板自动填**——只在打开时读一次，匹配「加入码 NNNN」就填，不自动加入。下面「或」+［建队］次按钮，忙碌态在建队键上。
2. **输满 4 位 → 队伍卡片**：发起人头像和昵称 · N 人 · 多久前建 +［加入］。码不对（含已回收）：四格变红 + 页内一句，不清空。已在别的队伍：卡片多一行警示色「会退出现在的队伍」，不再点一次。服务端加按码只读查询接口（§10）。
3. **未登录**：输满码或点建队时打开登录页盖在队伍页上，一句登录理由；登录成功自动接着查码出卡片 / 建好进对话。
4. **权限不拦**：建队 / 加入不要定位。进对话后没定位就弹系统框，第一次进队同时问通知；拒绝照样在队里，对话里常驻提示条「队友看不到你」［开定位］。

**昵称与头像**（新功能，账号自带，所有队伍通用）
5. 不再按队伍起称呼。**默认昵称** = 山野动植物名 + 两位随机数（如「岩羊27」），名表见附录 A（首字互不相同，与手机号无关，不查重）。规则：去首尾空格后 1–12 字，可用表情，不限次数；改名要联网，不做离线排队。
6. **头像**：系统照片选择器（免权限）→ 全屏裁剪页（黑底、圆形取景框、可拖、双指缩放，最小刚好盖满圆框，不旋转）→ 256×256 JPEG（约 20 KB）上传，挂在账号上，复用对话图片的存法；换头像换新 id、删旧图；不计入照片额度。可「不用头像」回到首字。只在设置顶行、账号页、队伍（圆点、对话、成员）出现；公开轨迹和导出不带。
7. **圆点**：有头像 = 照片 + 紫色描边（停止共享变灰空心）；没有 = 紫底昵称首字。首字撞了不处理。气泡、成员行用同一头像。
8. **推送与缓存**：改名、换头像后服务端向当前队伍广播「成员资料变了」，当场刷新，旧消息也显示新名；已结束的队伍打开时现查；不插系统消息。头像按 id 缓存，id 不变不重下；没网又没缓存显示首字。
9. **审核**：现在不审；**上架应用商店前补审核**。

**对话**
10. 顶栏：「队伍 4827」，副标题「3 人」/「已结束」；右侧［邀请］+ ⓘ 队伍信息。
11. **邀请**：直接调起系统分享，文字为加入码 + 下载链接（GitHub Release latest；以后换 OSS 或官网只改这一处），产品名写「星径」。不做链接加入、二维码。
12. 空状态：一句 + 大字加入码 +［邀请］，有消息后收起。有人加入 / 退出出居中系统消息（服务端补）；后加入的人看得到之前的消息。
13. 输入行：📍 位置、🖼 图片 + 输入框 + 圆形发送。
14. 发送：气泡立刻出现、变淡 = 发送中；失败留在原处「⚠ 没发出 · 点一下重发」，不弹提示条。离线：顶栏下状态条，消息排队、有网自动发。图片在气泡上显示进度。
15. 实时连接断开超过 10 秒才在队伍页、对话、队伍信息出状态条「正在重新连接」；地图上不出。
16. 📍 没定位：图标转圈，定到自动发；60 秒没定到出提示条。位置消息「📍 位置 · 1.3 km」，点了回地图飞过去。

**看队友**
17. 点圆点 → 小抽屉：头像 / 首字、昵称（发起人标出）、几时更新或「11:05 停止共享」、距离 · 方向 · 电量，有队伍轨迹加沿轨；只放信息。

**队伍信息**（二级页）
18. 自上而下：成员（自己第一，发起人标出，点队友展开最后位置）→ 我的位置（共享开关；省电开关「每 2 分钟更新一次」，不共享时变灰）→ 队伍轨迹 → 最下面红色线框危险区（发起人「结束行程」，所有人「退出队伍」）。
19. 队伍轨迹：发起人点「选一条 / 更换」→ 我的轨迹抽屉的**选择模式**（同 §8.5 的行，按加入时间倒序），点一条就绑定，提示条［撤销］。

**停止共享 / 结束行程 / 退出**
20. 共享开关一关就生效，提示条 4 秒；队友那边你变空心。
21. **结束行程**：［再点一次结束行程］（3 秒复原）。成功就变，不等推送：回到对话，末尾卡片「行程已结束」+［新队伍］，副标题「已结束」，对话照常可发。队员在地图上：提示条 4 秒，队友圆点马上消失。［新队伍］回队伍页；建 / 加入新队伍时旧对话一并离开。
22. **退出队伍**：［再点一次退出队伍］，不做撤销。退出后回地图，提示条 4 秒。
23. 底栏「队伍」不带数字，有未读带红点。

**不做**：邀请链接 / 二维码（官网下载页上线后再评估）；按队伍起称呼；进队提示设昵称；首字撞了的区分；底栏人数；退出撤销；队友小抽屉里的动作；地图上的连接状态。

屏 × 状态矩阵：见 [#163 结论](https://github.com/zibyn/stars-outdoor/issues/163)。

### 8.5 ⑤ 管理

来源：[方案：⑤ 管理的逐步方案](https://github.com/zibyn/stars-outdoor/issues/164)、[评估：我的轨迹排序与筛选](https://github.com/zibyn/stars-outdoor/issues/155)。原型 `prototype/ux-v3-manage`。文案 ⑤（C5-xx）。

**列表**
1. 轨迹行两行：名字；「10月5日 · 12.4 km · ↑860 m」。计划轨迹名字前加图标、不写日期；参考中 / 已公开在行尾加小图标。不做缩略图。
2. **顺序：按加入这台手机的时间倒序**（记录按开始时间，导入 / 同步 / 队伍下发按进来的时间）；行里日期仍是走的日期。轨迹表加一列加入时间（§10）。不做排序控件和筛选。
3. 只有点按：长按同点按，不做左滑；改名、导出、删除都在详情 ⋮。
4. 「轨迹 / 标注」是 M3 主页签，在抽屉顶栏下，进详情不显示，记住上次的页签。
5. 空状态：轨迹页签「还没有轨迹」+［导入］；标注页签「长按地图就能标注」+［回地图］。

**叠加**
6. 行尾叠加开关：空心图标；叠加后变成线的颜色块并打勾。线不在视野里就移镜头看全，抽屉保持半屏，不出提示条。不设上限，4 色循环；同色的线点一下看名字。
7. 标注组、单个标注的叠加不计入，用标注的点样式。
8. 全部取消：提示条「已取消 5 条叠加」［撤销］。
9. 叠加集合存在本机，不同步（沿用 v2 §9.2 的存法，去掉色序号分配，改按叠加先后循环取色）。

**标注**
10. 结构：标注组在上（📁 组名 · n 个 · 叠加开关）；小标题「不在组里」下是单个标注（📍 名字；「日期 · 海拔」· 叠加开关）。点组进组内列表，组内 ⋮ 改名 / 删除。
11. 点单个标注：标注编辑在抽屉里接上（取代整页 `WaypointScreen`），镜头飞到这个点。
12. 新建标注组：标注页签顶栏 ＋ → 小抽屉，占位示例组名，［取消］［建立］；空名不能建立；重名在输入框下写；建好新行短暂高亮，不出提示条。
13. 导入只有标注的文件：自动建组，切到标注页签并高亮，提示条「已导入 · 23 个标注」。

**导出**
14. ⋮ → 导出 → 小抽屉两行：GPX（大多数 App 和手表）、KML（奥维、Google 地球）；有照片加一行说明导出为压缩包。文件名用轨迹名。后台做，超 300 ms 行内转圈，好了调系统分享；失败提示条 + 重试。

**删除**
15. 轨迹、标注组、单个标注一律**软删除** + 提示条［撤销］8 秒；删组写数量；撤销后原位回来并高亮。提示条消失后才真删（本机先隐藏，过期再删并同步）。

**不做**：缩略图、长按菜单、左滑删除、叠加上限、排序和筛选（有人反馈找不到或常见超过约 50 条时，先做按名字搜索）。

屏 × 状态矩阵：见 [#164 结论](https://github.com/zibyn/stars-outdoor/issues/164)。

### 8.6 ⑥ 设置、账号、离线地图管理

来源：[方案：⑥ 设置、账号、离线地图管理的逐步方案](https://github.com/zibyn/stars-outdoor/issues/165)、#156、#166。原型 `prototype/ux-v3-settings`。文案 ⑥（C6-xx）。

**设置页**（一级页）
1. 四块：
   - 顶行自己：头像 + 昵称 +「同步 · 14:05」；没登录：圆形占位 +［登录］+ 登录理由。
   - 出发前：出发前检查，行尾列没过的项的图标，全过 ✓，点开 §8.3 的抽屉。
   - 记录：惯用手、偏离提醒。
   - 地图：地图缓存。
   - 最底下「关于 · 版本 1.0.3」。
2. M3 列表行，左图标；能进去的行右边放当前值和 ›；二选一 / 三选一用分段按钮就地改（选中实底 + ✓）。每行 ≥ 56 dp。
3. 偏离提醒：分段按钮 30 / 50 / 100 m，默认 50，下次记录生效。
4. 地图缓存：行里「2.2 MB / 1 GB」，点开小抽屉：上限分段 256 MB / 1 GB / 4 GB，一句说明；［再点一次清除］，清完提示条；失败写在抽屉里 + 重试；0 MB 时清除不能点。

**登录与账号**
5. 登录页（二级页）：一句登录理由；手机号带 +86；获取验证码按钮转圈后倒数；**验证码输满 6 位自动登录**；出错页内四类原因。
6. 登录后同步自动开，回设置页，提示条「已登录 · 同步中」；第一次登录给默认昵称。
7. **账号页**（「个人信息」和「账号与同步」合成一页）：大头像 → 昵称 › → 手机号（只读）→ 同步开关（副标题只写上次同步时间）→「照片只在 Wi-Fi 下上传」开关 → 退出登录 → 最底红字注销账号。删掉 41 字同步说明。
8. 退出登录：再点一次；在队伍里时按钮上方一句说明也会退出队伍。退出后回设置，提示条「已退出 · 本机轨迹还在」。
9. 注销：小抽屉，三行图标短句（云端轨迹和标注删除、公开轨迹从路网撤下、退出队伍）+「本机轨迹会保留」；红按钮［再点一次注销］；没网不置灰，点了在抽屉里说原因 + 重试。
10. 昵称：小抽屉，输入框带字数，空名不能保存；失败页内 + 重试；成功不出提示条。头像：没头像直接开系统选择器；有头像出「换一张 / 不用头像」；裁剪页［取消］［用这张］；上传中头像上转圈，失败提示条 + 重试，保持旧头像。

**关于**
11. 应用名 + 版本一行大字；去掉「（1）」和「要新版本请联系发布者」。
12. 「数据来源 ›」二级页：来源 / 许可两列表格，每行可点带外链图标；下面 OSM 抽取脚本链接。天气来源也在这里。

**离线地图管理**（一级页）
13. 顶栏右 ＋ 导入文件；标题下一行「共 20 MB · 手机剩余 12 GB」。
14. 每行：类型图标（沿线 / 附近 / 导入）+ 名字；第二行「大小 · 日期」，导入的写「导入 · 底图 / 等高线 / 地形」；有新版本行尾［更新］。去掉常驻的「删除」。
15. **点一行 → 回地图画出这个包的覆盖轮廓并缩放到能看全**，提示条「{包名} · 7.5 MB」，关掉提示条轮廓也消失（新功能，#156）。轮廓来自服务端在包里多放的实际裁剪 GeoJSON；旧包没有就用请求框或轨迹外接矩形。不做常驻离线范围图层。
16. ⋮：更新 / 删除；删除软删除 + 撤销，提示条消失后才删文件。
17. 下载中那行带进度条，进度同时在状态条。
18. 空状态：图标 + 一句 +［回地图］+ 小字「长按地图可下载附近」。

**不做**：设置里的离线地图入口；离线范围常驻图层；检查更新（#51）；关于页的公开承诺（mvp §1.4）和捐赠入口，暂不考虑。

屏 × 状态矩阵：见 [#165 结论](https://github.com/zibyn/stars-outdoor/issues/165)。
