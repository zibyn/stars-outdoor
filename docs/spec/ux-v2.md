# 星径体验改版规格（ux-v2）

> 状态：草案，待开发者确认（2026-09-29）。术语以仓库根目录 [`CONTEXT.md`](../../CONTEXT.md) 为准。
> 本文是界面（布局、按钮、抽屉、动画、文案、图标、路径）的准据；功能规则仍以 [`mvp.md`](mvp.md) 为准。两者冲突时界面以本文为准，mvp.md 里已被取代的段落都标了「见 ux-v2 §x」，清单见 §10.2。
> 来源：[Wayfinder: 体验改版（图标、文案、布局、路径、交互模式）](https://github.com/zibyn/stars-outdoor/issues/61)，规格与切片：[决定：体验改版规格与切片](https://github.com/zibyn/stars-outdoor/issues/79)；同屏的沿轨里程相关决定来自 [Wayfinder: 沿轨里程、队伍轨迹与手表对接](https://github.com/zibyn/stars-outdoor/issues/81)。

## 1. 范围与约束

### 1.1 范围

- 只改体验：图标、文案、布局、使用路径、交互模式。
- 例外，两处功能行为改动已获批：一键标注当前位置（§9.1）、多条轨迹 **叠加**（§9.2）。
- 其余业务逻辑、数据结构、接口、离线同步机制都不变。
- 不在范围：标注类型预设（要加字段）；App 启动图标（[App 没有启动图标](https://github.com/zibyn/stars-outdoor/issues/80)）；审查中发现的缺陷（[离线时队伍对话里打的字会丢](https://github.com/zibyn/stars-outdoor/issues/70)、[一键求助遇到非离线错误就不再重试](https://github.com/zibyn/stars-outdoor/issues/71)、[不属于任何轨迹的标注无法导出](https://github.com/zibyn/stars-outdoor/issues/72)）。

### 1.2 约束

- [决定：交互原则与信息架构](https://github.com/zibyn/stars-outdoor/issues/8) 的 7 条产品原则（mvp.md §1.3）全部保留，逐条验收。其中的信息架构部分被本文取代（§10.1）。
- 所有点击区 ≥ 56 dp（关闭按钮 `close` 例外，48 dp，见 §7）。
- 按钮形式规则见 §2.3。

## 2. 交互模式

[原型：整体交互模式对比](https://github.com/zibyn/stars-outdoor/issues/69)（选 B「规划 / 活动分离」）、[决定：规划状态与活动状态的按钮清单、位置和展开方式](https://github.com/zibyn/stars-outdoor/issues/73)

### 2.1 两种状态

| | **规划状态** | **活动状态** |
|---|---|---|
| 何时 | 没在记录（含不记录、只看地图走路） | 记录中（含暂停） |
| 进入 / 退出 | 结束记录后回到这里 | 点「开始」进入；按住「结束」退出 |
| 取向 | 信息多、入口齐全 | 大字数据 + 少数大键；戴手套、单手、强光、离线 |
| 首屏 | §3.1 | §3.3 |

- 同一张地图，两种状态只换叠在上面的控件；切换用一次标准档淡入（§5）。
- 规划状态下 App 在前台亮屏时持续定位（沿轨里程、定位按钮都靠它），退后台或锁屏即停，不用前台服务（mvp §2.7）。
- 两套布局取代旧的四角布局和「常驻按钮 ≤ 4」（§10.1）。

### 2.2 惯用手

- 设置页「惯用手：右手（默认）/ 左手」。
- 选左手时整体镜像：惯用手一侧的按钮列、活动状态另一侧的两个按钮、活动状态底部三个大键。顶部栏、底栏不镜像。
- 下文按右手描述：惯用手一侧 = 右侧。

### 2.3 按钮形式

| 形式 | 用于 |
|---|---|
| 纯图标 | 定位、图层、+/−、指南针、搜索 |
| 图标 + 2–4 字标签 | 标注、底栏五项、活动状态的「队伍」 |
| 必须有文字、醒目 | 求助（红底，只用文字不用图标）、分享位置、有人失联时的「队伍」（红字「N 人失联」）、地图上的失联标签 |

## 3. 首屏

### 3.1 规划状态布局

```
┌──────────────────────────────────────┐
│ [ 搜索地点、山峰、坐标          ] [图层]│  顶部栏
│ ┌──────────────────────────────────┐ │
│ │ 沿轨里程 · 正向                  │ │  参考轨迹条（没有参考轨迹时不出现）
│ │ 3.0 / 13.8 km    ±8 m · 全长 16.9 km│ │
│ └──────────────────────────────────┘ │
│ [ 离线中：已下载的地图和记录照常可用 ]│  状态条（只在出问题时）
│ [ 大风 · 14:00 到山脊，阵风 19 m/s  ×]│  出行提醒 / 测距横幅
│                               [指南针]│  地图不是北朝上时
│                                      │
│                (地图)                │
│                                      │
│                                [定位]│  惯用手一侧
│                              [+标注] │
├──────────────────────────────────────┤
│ 我的轨迹   队伍 3   ( 开始 )  离线地图  设置│  底栏
└──────────────────────────────────────┘
```

- **顶部栏**：搜索框（点开搜索整页）+ 图层（纯图标，开图层抽屉）。图层在惯用手一侧，镜像时不动（§2.2）。
- **顶部堆叠**（上 → 下，不出现的项不留空位）：
  1. 顶部栏
  2. 参考轨迹条（§3.2）
  3. 状态条（§3.6）
  4. 出行提醒横幅 / 测距横幅（可关闭；两者同时出现时出行提醒在上）
- **惯用手一侧**（底栏上方，上 → 下）：定位（纯图标，§3.5）、标注（纯图标，§9.1，[#122](https://github.com/zibyn/stars-outdoor/issues/122)）。
- **指南针**：纯图标，地图不是北朝上或有倾斜时出现在顶部堆叠下方、惯用手一侧（§3.5）。
- **底栏**（图标 + 文字，五项，不加「更多」）：我的轨迹 / 队伍 / **开始** / 离线地图 / 设置。
  - 这是入口栏，不是 Tab：点「开始」开始记录，其余四项打开整页或抽屉（§4），地图始终是首屏。
  - 「开始」居中大圆键，点一下直接开始记录（第一次只申请定位和通知权限，§8 路径 3）。
  - 「队伍」：未入队显示「队伍」，点开是创建或加入；入队后显示「队伍 N」（N = 在线人数）；有人失联时换成红字「N 人失联」；对话有未读时加小红点，不显示数字。
  - 「设置」：有新版本时加小红点（mvp §2.13）。「账号与同步」「关于」在设置页里。
- **不加缩放按钮**（双指缩放）。
- **不再出现**：菜单按钮与菜单抽屉、「上一条轨迹」、「下载当前视野」、首屏求助按钮（规划状态的求助在队伍抽屉，§4.4）。

### 3.2 参考轨迹条

规划状态下有 **参考轨迹** 时，显示在顶部栏下面（[原型：沿轨里程与里程标注的显示方式](https://github.com/zibyn/stars-outdoor/issues/83)）。它就是 #73 所说的「参考轨迹摘要」。界面元素名，不是领域词。

| 情况 | 显示 |
|---|---|
| 正常 | 上方小字「沿轨里程 · 正向 / 反向」；一行大字 **沿轨里程**（多值从小到大全列：「3.0 / 13.8 km」）；右侧定位精度和全长（「±8 m · 全长 16.9 km」） |
| 定位精度差于 50 m | 数字和位置点置灰，右侧写「精度差 ±80 m」。**此时不另出「定位不准」状态条** |
| 离参考轨迹超过 60 m | 大字「不在轨迹上」，小字「离轨迹 150 m」 |
| 还没有定位 | 大字「—」；状态条照常显示「正在定位…」 |

- 点条打开参考轨迹抽屉（§4.3）。
- 活动状态不显示这个条，沿轨里程进顶部数据（§3.4）。

### 3.3 活动状态布局

```
┌──────────────────────────────────────┐
│ 沿轨 7.3 km                      ● ○ │  顶部数据（深色，点一下翻页）
│ 5.62      │ 1:42      │ 420          │
│ 已走 km   │ 用时      │ 爬升 m       │
├──────────────────────────────────────┤
│ [ 定位不准 · 偏离提醒暂停 ]           │  状态条（只在出问题时）
│                               [指南针]│
│ [队伍 3 ]                      [图层]│
│ [分享位置]                     [ + ] │
│ [≡ 更多 ]                      [ − ] │
│                (地图)          [定位]│
│                                      │
│ ┌────────┐  ┌────────┐  ┌────────┐   │
│ │  求助  │  │ Ⅱ 暂停 │  │ + 标注 │   │  底部三个大键
│ └────────┘  └────────┘  └────────┘   │
└──────────────────────────────────────┘

暂停后底部：
│ [ 求助 ]  [ ▶ 继续 ][ ■ 按住结束 ]  [ 标注 ] │
```

- **顶部数据**：§3.4。下面是状态条（§3.6），再下面是出行提醒 / 测距横幅。
- **惯用手一侧**（上 → 下）：图层、+ / −、定位；指南针在图层上方，按 §3.5 出现。
- **另一侧**（带文字）：「队伍」（同底栏的 N / 红字「N 人失联」/ 小红点规则）、「分享位置」、「更多」。
  - 「分享位置」打开小抽屉：「发到队伍对话」（入队时）、「分享坐标」（系统分享面板，文本含 WGS-84）、「共享我的位置」开关（入队时）。
- **底部三个大键**（右手时左 → 右）：**求助** / **暂停** / **标注**。
  - 求助：红底文字，按住 1.5 秒发出，按住时线性进度（§5）。未入队时不显示，另两个键位置不变。
  - 暂停后中间换成「继续」和「按住结束」（按住 1 秒）。
  - 结束后回到规划状态，自动打开刚记录那条轨迹的轨迹详情抽屉，提示条「已保存 · 5.62 km」。在通知栏结束时不补开（[决定：「上一条轨迹」按钮的去留与位置](https://github.com/zibyn/stars-outdoor/issues/68)）。
  - 「更多」打开小抽屉：我的轨迹 / 离线地图 / 设置（底栏的另外三项）。用文字按钮而不是纯「⋯」图标，保证记录中也找得到。
- **底栏不显示**。队伍对话从「队伍」抽屉进；图层抽屉里的「我的轨迹 · 已叠加 n 条」一行也能进我的轨迹整页。
- 开始记录时定位按钮自动进入跟随（§3.5）。

### 3.4 活动状态顶部数据

[决定：活动状态顶部数据加入沿轨里程](https://github.com/zibyn/stars-outdoor/issues/85)。点一下翻页，共两页，右上角页码点。

| | 有参考轨迹 | 没有参考轨迹 |
|---|---|---|
| 第一页 | 整行「沿轨 km」（多值全列）+ 三格 已走 km / 用时 / 爬升 | 四格 已走 km / 用时 / 爬升 / 海拔 |
| 第二页 | km 用时 / 剩余 km / 预计到达 / 电量 | km 用时 / 均速 / 最高海拔 / 电量 |

- 「剩余」= 全长 − 沿轨里程，按本机起算点设置算；有多个值或偏离时，剩余和预计到达显示「—」。
- 定位精度差于 50 m：沿轨那一行置灰。
- 偏离超过偏离提醒阈值（设置里，默认 50 m）：沿轨那一行显示「偏离 150 m」，警示色，同时触发 **偏离提醒**。这是数据行里的内容，不是状态条。
- 数字直接变，不做滚动动画（§5）。

### 3.5 定位按钮与指南针

- **我的位置**：地图上画自己的位置点（带精度圈）；启动时相机移到当前位置（原则 1）。
- **定位按钮**循环三态：

| 状态 | 图标 | 点一下 |
|---|---|---|
| 未跟随 | `location_searching`，线性 | → 跟随：相机回到我的位置 |
| 跟随 | `my_location`，填充 | → 朝向：地图随手机朝向旋转 |
| 朝向 | `navigation`，填充 | → 跟随：回北 |

  - 用手拖动地图即退回未跟随。
  - 跟随中每次新定位，相机 1 秒线性过渡（§5）。
  - 还没有定位时点按钮：按钮不变，状态条「正在定位」。
- **指南针**：纯图标 `explore`。地图不是北朝上、或有倾斜（2.5D）时出现；点一下回北、倾斜归零，朝向状态退回跟随。

### 3.6 状态条

[决定：文案语气与新旧对照表](https://github.com/zibyn/stars-outdoor/issues/75)、[决定：核心路径优化后的步骤](https://github.com/zibyn/stars-outdoor/issues/77)

- 只在出问题时出现。位置：规划状态在参考轨迹条下面（没有参考轨迹时在顶部栏下面）；活动状态在顶部数据下面。
- 同时有多个问题时只显示最要紧的一条，右侧写「+2」，点「+2」展开全部。条上带动作（「点这里打开」「切到地形」）的，点条就执行动作。
- 轻重顺序（上面的先显示）：

| 级别 | 情况（组内也按此顺序） |
|---|---|
| 1 定位 | 系统定位关着 > 没有定位权限 > 没有定位 > 定位不准 |
| 2 离线 | 卫星图 / 标准图离线用不了 > 位置没发出去（在队伍里时）> 离线 |
| 3 电量 | 电量低于 20%（不论是否在队伍里；共享降频仍按 mvp §2.11，逻辑不变） |
| 4 同步 | 同步失败（只在规划状态显示） |

- 规划状态有参考轨迹时，「定位不准」不出状态条，只在参考轨迹条上置灰（§3.2）。
- 文案见 §6.4。

### 3.7 距离阈值

几处数字相近但含义不同：

| 阈值 | 量的是 | 用在 | 超过时 |
|---|---|---|---|
| 60 m（固定） | 离 **参考轨迹** 的距离 | 规划状态参考轨迹条 | 「不在轨迹上 · 离轨迹 150 m」，不显示里程 |
| 偏离提醒设置（默认 50 m） | 离 **参考轨迹** 的距离 | 活动状态 | **偏离提醒**（震动 + 通知）+ 数据行「偏离 150 m」 |
| 50 m | 定位精度 | 标注 | 不直接保存，按钮图标转圈等待（§9.1） |
| 50 m | 定位精度 | 沿轨里程、状态条 | 里程置灰「精度差 ±80 m」；活动状态或没有参考轨迹时出「定位不准」状态条 |

规划状态本来就没有偏离提醒，所以规划状态的文案不提偏离提醒。

### 3.8 地图视觉层级

[决定：多条轨迹叠加的范围与图层层级](https://github.com/zibyn/stars-outdoor/issues/67)、[原型：沿轨里程与里程标注的显示方式](https://github.com/zibyn/stars-outdoor/issues/83)

线（上 → 下）：

| 层 | 对象 | 样式 |
|---|---|---|
| 1 | 记录中的线 | 红、粗、白描边；暂停分段、续记都要画 |
| 2 | **参考轨迹** | 蓝、加粗、白描边。上面再画 **里程标注**（白底、参考轨迹色描边的圆角牌，只写数字；1 / 5 / 10 km 随缩放；往返处合成「3 / 14」）、方向小箭头、「起」「终」，都随正向 / 反向和起点设置变化；「起」不能点 |
| 3 | **叠加** 的轨迹 | 调色板色 + 白描边；轨迹详情里打开的那条加粗、置顶；没叠加的详情轨迹临时用调色板外的中性深色、加粗，关掉详情即消失 |
| 4 | 队友 **尾迹** | 细线、无描边，与队友圆点同色 |
| 5 | **周边路网** | 细线、低饱和、α≈0.45，无描边；OSM 路径不再加粗高亮；公开轨迹的叠深效果需真机调不透明度 |

- 测距线（黑，细）在所有轨迹线之上。
- 点状元素都在线之上（上 → 下）：我的位置 > 队友圆点和失联标签 > 标注圆点 > 里程牌与「起」「终」。标注点、队友点保持现在的圆点样式。
- 里程标注只画在参考轨迹上（含轨迹详情预览），**叠加** 的轨迹和周边路网都不画。
- 叠加调色板 6 色：醒目、在底图上够深；避开记录红、参考蓝和详情临时线的中性深灰。和队友颜色（`memberColor`）撞色相可以，靠线宽和白描边区分（队友尾迹是无描边细线）。具体色值真机上定。

## 4. 抽屉与整页

| | 参考轨迹抽屉（§4.3） | 点参考轨迹条 |

| | 设置 | 底栏；含惯用手、偏离提醒阈值、电池设置、地图缓存、账号与同步、关于 |

| | 队伍管理 | 队伍抽屉底部：邀请、「共享我的位置」（同分享位置小抽屉里那个）、省电模式、退出队伍、结束行程（发起人）、指定队伍轨迹（发起人） |

- 地图上的抽屉同一时刻只开一个；开新的会替换旧的。

### 4.2 轨迹详情抽屉

从上到下：

1. 名称 + 来源小字（「来自 佳明 fēnix 7」/「由队伍位置共享生成」；没有来源不写）
2. 数据：距离 / 爬升 / 用时 / 日期（计划轨迹不显示用时）
3. 海拔剖面（带里程标注）+ 正向 / 反向
4. 主操作：「设为参考」「叠加到地图」（已叠加时「取消叠加」）
5. 沿线离线地图：「未下载 / 已下载 / 可更新」+ 下载按钮；下载中「下载中 42%」
6. 出发前电池引导行「出发前：防止手机在后台停掉记录 · 去设置」：只在点过「设为参考」或沿线下载之后、且还没设置过时出现。系统电池优化已关，或在引导里点过「知道了」，就算设置过
7. 天气（沿途天气与出行提醒）
8. 次要操作：导出（一个「导出」按钮，点开小抽屉选「GPX（大多数 App 和手表都能打开）」或「KML（奥维、Google 地球）」）、公开、删除（见 [删除轨迹](https://github.com/zibyn/stars-outdoor/issues/99)）。正在记录的轨迹没有删除；行程中的队伍轨迹不能删，点了提示先换队伍轨迹或结束行程。

- 其余属性（改名、描述、坐标纠偏）在次要操作区，文案见 §6.5。
- 打开时相机把整条轨迹放进视野（400 ms，§5）。

### 4.3 参考轨迹抽屉

- 海拔剖面：横轴是沿轨里程，整公里刻度；当前位置有几个值画几条竖线。
- 正向 / 反向（分段按钮）。
- 环线：「起点 · 在轨迹上选 / 恢复」。「在轨迹上选」= 在地图上点一下轨迹上的某处作为新起点。
- 「不再用作参考轨迹」。
- 与一键标注的「在地图上选」（屏幕中心十字 + 确认，§9.1）是两种交互，名字分开。

### 4.4 队伍抽屉

未入队时：创建队伍 / 输入队伍码加入（§8 路径 5）。入队后从上到下：

1. 标题行「队伍 4827 · 5 人」+ 右侧「看全队」（点一下把所有队友放进视野）
2. 红色「求助」，按住 1.5 秒。**只在规划状态显示**，这是规划状态唯一的求助入口；活动状态用底部大键
3. 成员列表，失联的排最前，不含自己。每行：

| 内容 | 规则 |
|---|---|
| 名字 | — |
| 沿轨里程 + 领先 / 落后 | 「7.3 km · 领先 0.8」；按 **队伍轨迹** 算；多值全列且不写领先落后；不在轨迹上「不在队伍轨迹上」；没有队伍轨迹时整段不显示 |

4. 「对话」（有未读时小红点）、「分享位置」
5. 「管理」→ 队伍管理整页

## 5. 动画

[决定：动画规范](https://github.com/zibyn/stars-outdoor/issues/74)。原则：短、稳、不打断。不做回弹或弹性效果。

| 档位 | 用在 | 进入 | 退出 |
|---|---|---|---|
| 快 | 按下反馈、开关、标注落点、提示条淡入淡出 | 100–150 ms | 同左 |
| 标准 | 抽屉、整页、规划 ↔ 活动切换（淡入） | 250 ms，减速 | 200 ms，加速 |
| 相机 | 回到我的位置、切朝向、回正 | 300 ms | — |

- **相机**：跟随中的新定位 1 秒线性；打开轨迹详情、点队友、点失联标签 400 ms，把目标完整放进视野；目标超过约 3 屏直接跳；手势完全跟手。
- **不做动画**：数字变化、列表项入场、求助发出后的确认、出行提醒横幅、记录中的红点（静止不闪）。
- **按住计时**：求助 1.5 秒、结束 1 秒，按钮上线性填满的进度条，不受任何动画设置影响。
- **系统「移除动画」**：所有过渡时长为 0，相机直接跳到位；按住进度照常。地图相机要手动判断这个设置。
- **震动**（各一下）：标注成功、开始、暂停、结束、求助发出、按住计时完成。偏离提醒的震动不变。普通按钮不震。
- **提示条停留**：

| 情况 | 停留 |
|---|---|
| 规划状态 | 4 秒 |
| 规划状态，带「撤销」或「补充」 | 6 秒 |
| 活动状态（含带撤销、补充的） | 8 秒，大字 |

## 6. 文案

[决定：文案语气与新旧对照表](https://github.com/zibyn/stars-outdoor/issues/75)

### 6.1 语气

| | 规划状态 | 活动状态 |
|---|---|---|
| 长度 | 完整的句子 | 主句 ≤ 8 字，需要时加一行补充 |
| 内容 | 可以解释原因和后果 | 只说结果 |

- 先说发生了什么，再说怎么办。不道歉，不用感叹号。
- 不单独用「请稍候」「稍后再试」：要么给时间，要么给动作。
- 尽量省主语；需要时用「你」，不用「您」。
- 兜底错误：「{什么}没成功 + 原因（知道的话）+ 下一步」。会自动重试的写明；不会自动重试、但再试可能成功的给「重试」按钮。只描述实际行为，不承诺没有实现的重发。

### 6.2 统一叫法与技术名词

- 记录：开始 / 暂停 / 继续 / 结束（不用「停止」「停止记录」）。
- 位置共享：**停止共享** / 继续共享；开关叫「共享我的位置」。
- 「点」，不用「点击」「点开」。
- 「求助」，不用「求救」「SOS」「发出求助！」。
- 「标注」：提示都这么叫；按钮只有图标，无障碍描述叫「标注」（[#122](https://github.com/zibyn/stars-outdoor/issues/122)）。
- 「叠加到地图」/「取消叠加」，不用「上图」「显示在地图上」。
- WGS-84 不在界面上显示，只留在分享出去的坐标文本里。
- 文件格式名不做按钮文字：「导入轨迹文件」「导入离线地图文件」，格式写在帮助小字里。
- 搜索来源说明（OpenStreetMap、Photon、天地图）挪进「关于」。
- 「检测到」「进程」之类不出现。

### 6.3 确认方式

删除离线包、删除标注、删除轨迹、退出队伍用「再点一次」：按钮原地变成确认文字，3 秒内再点才生效，不弹窗（和结束行程一致）。按住类（求助、结束）不另确认。

## 7. 图标

- **求助**：只用文字，不用图标（`sos` 图标印着「SOS」）。

## 9. 功能行为改动

### 9.1 一键标注当前位置

[评估：标注以「当前位置」为主的实现影响](https://github.com/zibyn/stars-outdoor/issues/64)、[决定：标注方式以一键标注当前位置为主](https://github.com/zibyn/stars-outdoor/issues/66)

- **入口常驻**：规划状态惯用手一侧、活动状态底部大键，都只有标注图标，界面上不显示 ±m 精度（#122）。记录中、暂停中都挂在正在记录的轨迹上；不记录时不属于任何轨迹。
- **质量门槛**：

| 情况 | 行为 |
|---|---|
| 定位 ≤ 30 s 且精度 ≤ 50 m | 直接保存，震动，提示条「已标注 · 撤销 · 补充」 |
| 否则 | 按钮图标转圈，达标自动保存；点一下取消 |
| 60 s 仍不达标 | 「定位信号弱」·「就用这里」/「在地图上选」/「取消」 |
| 没有权限 | 点按钮时才申请；拒绝后提示可以长按地图选点 |
| 系统定位关着 | 状态条「定位已关 · 点这里打开」，跳系统设置 |

- 不记录时，前台按需取一次定位，不启动记录服务。
- **在地图上选**：屏幕中心十字 +「确认」。从超时进入；定位按钮做好后也可以单独用于保存前微调。标注同步后位置不能改，微调只在保存前。
- **长按地图**保留：长按小抽屉 →「添加标注」。
- 「补充」打开命名和照片；不点，提示条按 §5 时长消失。
- **不变的**：不加精度或来源字段；数据库、同步、OpenAPI、服务端都不改。改动只在 `MainActivity` 和新增的定位辅助。以后需要精度时再以可空字段向后兼容地加。

### 9.2 叠加

[评估：多条轨迹叠加与视觉层级的实现影响](https://github.com/zibyn/stars-outdoor/issues/65)、[决定：多条轨迹叠加的范围与图层层级](https://github.com/zibyn/stars-outdoor/issues/67)

- 我的全部 **轨迹**（计划、导入、记录、下发）都可以 **叠加**；**周边路网** 是弱化的参考层。
- **入口**：我的轨迹列表每行一个叠加开关（≥ 56 dp），列表顶部「已叠加 n 条 · 全部取消」（直接清空，不可恢复）；轨迹详情「叠加到地图」；图层抽屉「我的轨迹 · 已叠加 n 条」，点进去跳到列表。
- **不做**：点地图上的线打开详情（活动状态下易误点）。
- **上限**：6 条；超出提示「最多叠加 6 条，先取消一条」，不自动挤掉。
- **颜色**：6 色调色板；叠加时分到最小的空闲色，取消前不变；不提供选色。
- **参考轨迹** 不用叠加也始终显示；同时被叠加时只画一次，按参考轨迹样式，但仍占一条名额和它的颜色，取消参考后按原色显示。
- **详情里的轨迹**、**记录中的线**、层级：§3.8。结束记录后不自动叠加。
- **周边路网** 仍是图层抽屉里一个总开关，不分子开关；样式改淡（§3.8）。
- **会改的**：本机 prefs 存叠加集合（轨迹 id → 色序号），读取时丢弃已不存在的 id；`RecordingService` 对内提供当前轨迹的点流；`style.json` 周边路网样式。每条轨迹一个 GeoJSON source + 描边层；轨迹点异步加载、按 id 缓存。
- **不变的**：数据库 schema、同步、OpenAPI、服务端都不改；叠加集合和颜色不同步。

### 9.3 其他只改界面的行为

都只显示已有数据或挪位置，不改数据和接口：

- 电池引导从第一次开始记录挪到轨迹详情和设置页（§8）。
- 电量低于 20% 显示状态条；共享降频规则不变（mvp §2.11）。
- 结束记录后自动打开轨迹详情（§3.3）。
- 去掉「下载当前视野」，加「下载这附近」（约 20 × 20 km，mvp §2.3）。
- 第一次组队先输码后登录（§8 路径 5）。
- 队友小抽屉、看全队、停止共享的空心点、电量标记、失联标签（§4.4、§4.5）。
