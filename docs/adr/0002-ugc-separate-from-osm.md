# 公开轨迹与 OSM 数据分层存放，互不合并

周边路网同时用到 OSM 路径和用户的公开轨迹。按 ODbL 和 OSMF 的 Collective Database / Horizontal Map Layers 指南，如果把公开轨迹吸附到 OSM 路径上、拿它补全或修正 OSM 路径，或用 OSM 数据给它纠偏去重，就会形成派生数据库，全部用户轨迹都得按 ODbL 公开。因此公开轨迹单独存在 PostGIS 里，作为独立图层渲染，**不做吸附、合并、纠偏、去重**。OSM 路径和徒步线路则按 ODbL 署名，并公开抽取脚本和标签筛选规则。

## Consequences

- 以后如果有人想"把用户轨迹吸附到路网上让它更好看"，或者"用用户轨迹去修补 OSM"，都会触发 share-alike。这不是疏忽，是刻意的边界。
- 平台轨迹（港台官方开放数据）同样作为独立图层，按各自的许可证署名。
