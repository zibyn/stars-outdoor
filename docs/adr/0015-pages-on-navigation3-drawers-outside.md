# 整页用 Navigation 3 的 NavDisplay 叠在地图上，抽屉不进返回栈

主界面是一张常驻的地图，上面一次只开一个 **抽屉**，再上面叠多层 **整页**。整页栈交给 Navigation 3：返回栈是我们自己持有的列表，根是地图；地图以上每个整页都用叠加场景（`OverlayScene`）画，所以地图和抽屉一直留在下面，不离开组合。这样我们得到官方的预测性返回、每页各自的状态保存，以及以后的深链。Navigation Compose（`NavHost`）一次只画一个页面，与常驻地图冲突，所以不用。**抽屉** 不进返回栈，因为它们一次只开一个、新开的替换旧的，地点小抽屉还能盖在我的轨迹上，这些都不是栈的形状。抽屉由地图那一页自己的纯 Kotlin 状态管理。跨整页和抽屉的规则（比如导入或结束记录时关掉整页、在抽屉里打开详情，但登录页留着）写成纯函数，作用在返回栈列表和抽屉状态上，用 JUnit 测试。
