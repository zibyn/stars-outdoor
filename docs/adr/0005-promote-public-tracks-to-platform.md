# 公开即同意被晋升，晋升后的平台轨迹是独立副本

> **已废弃（2026-09-30）。** 平台轨迹的本意是平台运营、带描述和图片、供用户发现的精选线路，而"晋升公开轨迹为副本"偏离了这个本意；上线前也没有运营人手和可晋升的轨迹。平台轨迹、晋升及相关代码一并删除，周边路网只保留 OSM 路径、徒步线路和公开轨迹。精选线路以后重新设计，不沿用晋升 / 副本模型。

平台轨迹的本质是"平台确认可靠"，而不是出自谁：一条轨迹最初来自个人还是官方，App 不关心，也不单独导入、标注官方数据。平台轨迹全部由稳定的公开轨迹晋升而来。我们决定：用户公开一条轨迹，就默认同意它可能被晋升（写进服务条款，不逐条征求）；晋升时保存一份平台副本、署原作者名，原公开轨迹从公开轨迹图层隐藏；之后原作者删除或取消公开，副本保留。这样平台轨迹不会因个人操作而消失，才担得起"可靠"。

因为有了晋升和下架，平台轨迹不再是季度生成的静态文件，而和公开轨迹一样存进 PostGIS、在线出瓦片、打包时取快照；原先预置的港台开放数据不再导入，表初始为空。ADR 0002 照旧：平台轨迹和公开轨迹一样不与 OSM 吸附或合并。

## Consequences

- 服务条款必须在用户首次公开轨迹前写明"可能被晋升、晋升后撤回不影响副本"，否则默认同意站不住。
- 副本上署着原作者名，属于个人信息：原作者注销账号或要求删除时，至少要能去掉署名（改为匿名），这条流程上线前要定。
