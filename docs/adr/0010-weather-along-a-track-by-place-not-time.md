# 天气可以按轨迹沿线查看，但只按地点、不按时刻

ADR 0009 把天气改成「某个地点的数据」后，只能看我的位置或长按的点。可出发前最常问的是「这条线上的天气怎么样」：山顶和山脚能差十几度，风也不一样，一个点一个点去长按太麻烦。

改为：天气页顶部可以在「我的位置 / 参考轨迹 / 正在看的轨迹 / 长按的点」之间切换。选了轨迹，就沿线取几处地点：起点、约每 5 km 一处（最多共 8 处，长线就拉开间距）、最高点、终点，同一个 1 km 预报网格只取一处，环线的起终点算一处。页面上画出海拔剖面并标出这些地点，未来 48 小时有出行提醒的标红；点哪一处就看哪一处完整的逐小时预报，气温按轨迹点的海拔修正。轨迹详情里加一行「沿途天气」作入口。

ADR 0009 的核心不变：**不估算到达时间、没有配速档和出发时间**。每处给的都是同样的 48 小时，几点走到哪里由用户自己对照。

## Consequences

- 每处地点占一个网格配额，一条轨迹最多 8 个，配额足够。
- 沿途天气和长按的点一样不缓存；以后如果有人要在出发前看好、没信号时再翻，再存到本机。
- 顶部栏的天气按钮改成纯图标：这小时有雷阵雨显示雷雨，有降水显示雨，其余都显示通用的天气图标（预报里没有云量，不判断晴天）。按钮上不再显示气温。
